# Claims Status Update

Write status that is accurate, calm, and actionable. No internal jargon in customer-facing text.

## Steps

1. Confirm audience: customer, diary, agent, or attorney.
2. State where the claim is now in one sentence.
3. What happened since last update; what is blocked and why.
4. What we need from them (docs, inspection appointment, choice of shop).
5. When they should expect the next update.

## Output shape

**Internal diary note** and **customer-ready message** (separate).

**Done when:** both versions are consistent and the customer knows the next concrete step.
