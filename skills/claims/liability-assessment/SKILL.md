# Liability Assessment

Build a fault narrative from evidence, not assumptions. Separate **supported**, **disputed**, and **unknown**.

## Steps

1. Timeline of events from statements, photos, telematics, police report, scene diagram.
2. List each party’s duties and alleged breaches.
3. Score evidence strength (strong / medium / weak) per dispute point.
4. Propose liability split range and what would move it.
5. Note jurisdictional issues only if provided; otherwise flag as unknown.

## Output shape

**Scenario** · **Evidence table** · **Liability range** · **Investigation next steps** · **Settlement implications**

**Done when:** liability posture is explicit and every contested point has an evidence status.
