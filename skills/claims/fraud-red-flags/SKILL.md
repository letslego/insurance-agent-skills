# Fraud Red Flags (SIU Screen)

Identify **indicators for referral**, not guilt. Use neutral language. Prefer patterns + inconsistencies over vibes.

## Steps

1. Inventory anomalies: late report, prior claims clustering, inconsistent statements, vendor steering, unusual injury pattern, identity issues.
2. Cross-check timeline vs physical evidence vs prior history if available.
3. Score: no SIU needed / monitor / refer to SIU — with reasons.
4. List discreet investigation steps that do not tip off improperly.
5. Draft SIU referral note (facts only).

## Output shape

**Indicators** · **Inconsistencies** · **Referral recommendation** · **SIU packet bullets** · **What NOT to say to customer**

**Done when:** a clear refer/monitor/clear decision exists with factual support.
