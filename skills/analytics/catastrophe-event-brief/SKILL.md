# Catastrophe Event Brief

Create a short ops brief for storm/wildfire/quake/flood style events.

## Steps

1. Event facts known: type, timing, geographies, severity estimates if provided.
2. In-force exposure snapshot from provided data (policies, TIV, vehicles in ZIP list).
3. Claims surge expectations and staffing/vendor needs.
4. Customer messaging themes and FNOL surge tips.
5. UW/new-business posture recommendations if guidelines exist (moratoriums, inspections).

## Output shape

**Situation** · **Exposure** · **Claims ops** · **Customer messaging** · **UW posture** · **Open questions**

**Done when:** claims, UW, and CX leaders can act from one page.
