# Agent Coaching

Teach from the case without humiliation.

## Steps

1. Summarize what happened vs what good looks like.
2. Identify 1–3 skill gaps (process, empathy, product, compliance).
3. Provide a better talk track or checklist.
4. Give a practice scenario + model answer.
5. Define a measurable follow-up (next 5 interactions).

## Output shape

**Case lesson** · **Gaps** · **Better pattern** · **Practice rep** · **Follow-up metric**

**Done when:** the learner has a practiceable behavior change, not just feedback adjectives.
