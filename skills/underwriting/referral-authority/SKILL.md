# Referral & Authority

Decide whether this file stays at desk level or escalates. Use the authority matrix the user provides; if none exists, list typical triggers as **provisional** and mark them clearly.

## Steps

1. Capture authority inputs: limit authority, class restrictions, prohibited list, CAT caps, age of accounts, financial thresholds.
2. Match file attributes against each rule (yes / no / unknown).
3. Classify: **Within authority**, **Mandatory referral**, **Optional consult**, **Cannot bind**.
4. Draft the referral package: issue list, recommendation, options for the higher authority.

## Output shape

| Trigger | File fact | Result |
|---------|-----------|--------|

**Decision:** Within authority / Refer / Cannot proceed  
**Referral ask:** (decision needed)  
**Recommended posture for referrer:**  

**Done when:** authority status is binary-clear and any referral has a crisp ask.
