# Underwriting Decision Memo

Produce a file-ready memo another UW, referral underwriter, or auditor can follow.

## Steps

1. Confirm decision type: **Quote** / **Quote with modifications** / **Decline** / **Refer** / **Indicate only**.
2. Write one-paragraph risk abstract (who, what, where, size).
3. List decision drivers (max 7), each tied to a fact in the file.
4. State terms and price summary (or decline reasons coded to appetite/hazard/experience/financials).
5. List subjectivities and prior-to-bind requirements.
6. State authority/referral status.
7. End with next actions and owner (UW / broker / loss control).

## Memo template

```
Account / LOB / Effective:
Decision:
Risk abstract:
Drivers:
Terms summary:
Pricing summary:
Subjectivities:
Authority:
Decline/refer reasons (if any):
Next actions:
```

**Done when:** a peer can defend the same decision from the memo alone without re-reading the full submission.
