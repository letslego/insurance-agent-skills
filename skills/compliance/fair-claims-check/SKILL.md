# Fair Claims Process Check

Audit the file against fair-claims style duties using the checklist/rules you are given.

## Steps

1. Identify jurisdiction and applicable checklist source provided.
2. Check acknowledgment, investigation diligence, coverage decision timing, payment timing, communication cadence.
3. Flag breaches or near-breaches with date evidence.
4. Recommend cure actions and customer communications.
5. Summarize residual regulatory risk.

## Output shape

| Duty | Status | Evidence | Cure |
|------|--------|----------|------|

**Overall risk** · **Immediate cures** · **Owner**

**Done when:** every checklist duty is pass/fail/unknown with a cure if fail.
