# Repair Network QA

Review estimates for consistency with program standards and good faith repair practices.

## Steps

1. Summarize estimate: shop, DRP status, totals, cycle time.
2. Check common issues: betterment disputes, OEM vs aftermarket, unnecessary procedures, missing ops, prior damage.
3. Compare to photos/description for support.
4. Recommend approve / adjust / reinspect / escalate.
5. Draft shop-facing and customer-facing notes separately.

## Output shape

**Findings** · **Unsupported items** · **Recommendation** · **Shop note** · **Customer note**

**Done when:** the estimate decision is evidence-linked and communicable.
