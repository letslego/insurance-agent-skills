# Non-Renew Rationale

Produce a guideline-backed rationale that is consistent, documentable, and customer-safe.

## Steps

1. Confirm action type: non-renew, restrict coverage, remove driver/vehicle, re-underwrite.
2. Cite the specific guideline triggers from provided rules and file facts.
3. Check timing/notice requirements if provided; else flag as must-verify.
4. Draft internal rationale + customer/adverse-action language separately.
5. List remediation paths if any (what would allow rewrite later).

## Output shape

**Action** · **Triggers cited** · **Internal rationale** · **Customer notice points** · **Remediation (if any)**

**Done when:** the action can be defended from the cited facts and rules alone.
