# MVR / CLUE Review

Translate motor vehicle and claims history into underwriting action.

## Steps

1. Inventory report contents: violations, suspensions, accidents, prior claims, dates, chargeability if provided.
2. Map each item to guideline treatment (ignore / surcharge / decline / refer) using provided rules.
3. Note data quality issues (mismatched identity, duplicate claims, incomplete years).
4. Summarize household risk impact across drivers/vehicles.
5. Recommend UW posture and customer explanation points.

## Output shape

**Item table** · **Guideline mapping** · **Household impact** · **UW recommendation** · **Customer talk track**

**Done when:** every report item has a disposition tied to a rule or an explicit gap.
