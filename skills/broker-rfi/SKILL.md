# Broker RFI

Ask for the **minimum** information that unblocks a decision. Group questions; avoid fishing expeditions.

## Steps

1. State why the file is blocked (decision, price, terms, or appetite).
2. Rank gaps: **Blocker** / **Material** / **Nice-to-have**.
3. Write concise questions; one fact per question; specify format (loss runs valued through date, SOV columns, etc.).
4. Offer acceptable alternatives when useful (e.g., 4-year losses if 5th year unavailable).
5. Set a clear "we can quote when…" condition.

## Output shape

**Email/subject line**  
**Context (2–3 sentences)**  
**Blockers** (numbered)  
**Material follow-ups**  
**Nice-to-have**  
**Quote condition**

**Done when:** every blocker question is answerable with a document or a yes/no, and the broker knows what unlocks a quote.
