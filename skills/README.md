# Skills

Insurance Agent Skills are grouped by desk area:

| Folder | Focus |
|--------|-------|
| `knowledge/` | Router, citations, coaching, handoffs |
| `underwriting/` | Submissions, appetite, pricing, memos |
| `claims/` | FNOL through subrogation |
| `customer/` | Quotes, counseling, retention, complaints |
| `personal-lines/` | MVR/CLUE, telematics, household, non-renew |
| `compliance/` | Regulator, fair claims, QA |
| `analytics/` | Filings, LR, CAT briefs |

Start with [`knowledge/ask-insurance`](./knowledge/ask-insurance/SKILL.md).
