# Retention Save

Attempt a save **inside approved offers**. Never invent discounts or underwriting exceptions.

## Steps

1. Learn cancel reason (price, claim experience, life change, competitor, service).
2. Diagnose if the issue is price, coverage, or trust.
3. Check eligible save levers from provided guidelines (deductible, telematics, bundling, payment plan, loyalty).
4. Present 1–2 save options + what happens if they still leave (effective date, refunds, proof of insurance needs).
5. Log outcome and follow-ups.

## Output shape

**Reason** · **Eligible levers** · **Save offer script** · **If-they-leave checklist** · **Outcome log fields**

**Done when:** either a compliant save path is offered or a clean cancel handoff is prepared.
