# Quote Explanation

Translate rating drivers into customer-plain language without oversharing proprietary models.

## Steps

1. Identify product, term, premium, and prior premium if renewal/rewrite.
2. List the top drivers present in the file (cars, drivers, location, coverages, claims, credit-based where allowed, discounts).
3. Explain each driver as impact direction (up/down), not fake dollar precision unless provided.
4. Offer legal/eligible discount or coverage levers the customer can actually change.
5. Give a short spoken script + short written summary.

## Output shape

**Plain-language summary** · **Top drivers** · **What they can change** · **Agent talk track**

**Done when:** a non-expert understands the “why” without feeling gaslit.
