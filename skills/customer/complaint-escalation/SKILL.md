# Complaint & Escalation Handling

De-escalate with structure: acknowledge → clarify → resolve path → confirm.

## Steps

1. Capture complaint theme (billing, claim delay, rate, service, coverage denial) in the customer’s words.
2. Pull facts already known; list what must be verified.
3. Classify: resolve now / needs specialist / regulatory risk.
4. Propose resolution options within authority; escalate path if not.
5. Draft empathy-first customer response + internal escalation brief.

## Output shape

**Issue statement** · **Facts** · **Resolution options** · **Customer reply draft** · **Escalation brief**

**Done when:** the customer has a next step and ownership is clear.
