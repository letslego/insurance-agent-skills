Install

Native plugins for Claude Code and Codex, plus a one-liner for Cursor and other agents.

Add the marketplace, install the plugin, reload — then use slash commands.

/plugin marketplace add letslego/insurance-underwriting-skills
/plugin install insurance-underwriting@insurance-underwriting-skills
/reload-plugins

CLI: claude plugin marketplace add letslego/insurance-underwriting-skills then claude plugin install insurance-underwriting@insurance-underwriting-skills

Fastest path — copy editable skills with skills.sh:

npx skills@latest add letslego/insurance-underwriting-skills

Or clone the repo and enable the Insurance Underwriting plugin from Codex /plugins (manifest at .codex-plugin/plugin.json).

Works with any Agent Skills–compatible harness:

npx skills@latest add letslego/insurance-underwriting-skills

Or clone and point your agent at the skills/ directory.

How underwriters use the pack

One composition of the desk loop — invoke the full flow or cut in at the step you need.

  1. IntakeMap the file and gaps
  2. AppetiteIn, out, or refer
  3. RiskLosses, hazards, financials
  4. TermsStructure the coverage
  5. PriceTechnical → target → walk-away
  6. AuthorityDesk bind or escalate
  7. DecideMemo, RFI, or renewal stance

Unsure where to start? Run /ask-underwriter. For a full file, run /underwrite-submission.

Decision support, not bind authority

These skills help structure analysis and write-ups. They do not replace carrier guidelines, your authority matrix, actuarial models, or licensed professional judgment. Cite your appetite docs in-session so the agent can ground recommendations in your rules.
